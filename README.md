# Carbon Thread Website

A modern, responsive website for Carbon Thread - Making sustainability compliance accessible to all.

## 🌱 About Carbon Thread

Carbon Thread is a global team of environmental specialists helping organizations quantify and reduce their environmental impact through data-driven insights. We make sustainability compliance accessible, transparent, and affordable — no matter your company's size or geography.

## 🚀 Features

- **Responsive Design**: Fully responsive layout that works seamlessly across all devices
- **Modern UI/UX**: Clean, professional design with smooth animations and transitions
- **Performance Optimized**: Webpack-optimized build with code splitting and lazy loading
- **SEO Ready**: Comprehensive meta tags for search engines and social media
- **Accessibility**: Built with web accessibility standards in mind
- **Interactive Elements**: Smooth scrolling, mobile navigation, and dynamic content loading

## 📋 Services Showcased

- **Life Cycle Assessments (LCA)**: Comprehensive cradle-to-grave environmental impact analysis
- **Environmental Product Declarations (EPD)**: Verified product footprint communication
- **Carbon Accounting**: GHG emissions quantification across Scopes 1, 2, and 3
- **Sustainability Advisory**: Regulatory compliance and strategic consulting

## 🛠️ Tech Stack

- **HTML5**: Semantic markup structure
- **CSS3**: Custom properties, Grid, Flexbox, animations
- **JavaScript (ES6+)**: Modern JavaScript with modules
- **Webpack 5**: Module bundling and optimization
- **Development Server**: Hot module replacement for development

## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/your-org/carbon-thread-website.git
cd carbon-thread-website
```

2. Install dependencies:
```bash
npm install
```

## 🔧 Development

Start the development server with hot reload:
```bash
npm start
```
or
```bash
npm run dev
```

The site will be available at `http://localhost:8080`

## 🏗️ Build

Create a production build:
```bash
npm run prod
```

The optimized files will be in the `dist/` directory.

## 🎨 Customization

### Colors
The color scheme can be customized in `src/styles/main.css`:
- Primary Color: `#2c5530` (Forest Green)
- Secondary Color: `#5a8d60` (Sage Green)
- Accent Color: `#8bc34a` (Light Green)

### Content
All content is contained in `src/index.html` and can be easily edited.

### Styling
Global styles and component styles are in `src/styles/main.css`.
